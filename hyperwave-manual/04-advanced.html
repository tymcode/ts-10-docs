TS‑10 / TS‑12 · Hyper-Wave Programming

III. Advanced Hyper-Wave Applications

In the first tutorial, we used Hyper-Wave programming to create a single cohesive sound that undergoes distinctive timbral change throughout its duration. In the second tutorial, we took an entirely different approach, instead creating two Hyper-Wave voices (from a single wave-list) that provided repetitive patterns of individual notes. When used this way, a Hyper-Wave voice acts almost as a rudimentary sixteen-step sequencer. The pitch, volume, and duration of each note can be independently set, as can its timbre (by the act of selecting a different wave for each step) and even wave direction. The major difference between the two approaches lies in whether or not crossfades are used—if they are not, the result is a distinct pattern of notes; if they are, the result is a single cohesive sound.

However, the exercises presented in these two tutorials are really only the tip of the iceberg when it comes to Hyper-Wave programming. Here are a few additional suggestions for advanced Hyper-Wave applications:

  • Hyper-Wave voices normally loop as long as a key is held down or as long as Envelope 3 permits. However, you can create a Hyper-Wave voice that doesn’t loop, as long as it has fifteen or fewer steps. Here’s how to do it: Set the LOOPSTART value to be one greater than the END value (in other words, if the END value is 8, make the LOOPSTART value 9). Then, in the Time sub-page, set the LOOPSTART step (in this example, step 9) to its minimum volume (−50 DB). Finally, in order to remove any potential low-level sound which may come from that last step (which is actually looping indefinitely, though attenuated −50 DB), set the sustain level of Envelope 3 to 0 and adjust the decay 3 time accordingly.

  • The fact that the direction of each wave step can be independently set to forward or reverse allows you to create fascinating forward-backward sounds. For example, a fairly common studio trick is to have a backwards snare drum sound segue into the “normal,” forward version of that sound. This creates a unique effect, where the sound appears to suck inward. To recreate this with Hyper-Wave programming, create a wave-list that has a START-STEP of 1, a LOOPSTART of 3, and an END of 2. Then set the volume of step 3 to −50DB and set the sustain level of Envelope 3 to 0, with a decay 3 time of about 20. As described in the paragraph above, this will result in a Hyper-Wave voice that does not loop. Choose a snare drum wave for steps 1 and 2, and, in the Pitch sub-page set the direction of wave step 1 to REVERSE. To make sure you get the full attack of step 2, use no crossfade time (a value of 00000) and set Envelope 3’s attack time to 00. You may want to experiment with using the same or different snare drum waves for steps 1 and 2 (a reverse FUNKSNARE going into a forward ROCKSNARE is particularly effective) and you might also want to experiment with various effect types (TIGHT AMBIENCE and GATED REVERB are two that work well).

  • Any kind of wave class—including Transwaves—can be incorporated into Hyper-Wave voices. When using Transwaves in a Hyper-Wave voice, entering different values into the START parameter (in the main Wave-List Editor page) will cause distinct timbral change. For example, create a sixteen-step Hyper-Wave voice (START-STEP=1; LOOPSTART=1; END=16) and assign the same Transwave to each of the sixteen steps. Then enter a different START value for each of the sixteen steps. Play and hold a note on the keyboard. Each wave step—though accessing the same wave—produces a significantly different sound, since it is accessing a different area of the same wave. To hear how this works in context with other sounds, call up the program you created in the second Tutorial and, in voice one (the only Hyper-Wave voice), change the wave for all sixteen steps to BELL-XWV2 (from the TRANSWAVE wave class). Enter a different START value for each of the sixteen steps (you can just randomly enter values here). Now play and hold a note on the keyboard. You’ll hear the original three drone voices playing along with this randomly changing Transwave sound. For an even better blend, try transposing each of the sixteen wave steps up two or three octaves (this will help better separate the Hyper-Wave voice from the other three, which are all playing a fairly low register).

  • After you’ve created a basic Hyper-Wave voice, take the time to experiment with applying different modulation sources (in both positive and negative amounts) to the five different Hyper-Wave modulation destinations. Particularly interesting effects can be created by using periodic sources such as the LFO or (for great random effects that completely remove the regularity from the wave-list loop) the noise generator. Aperiodic modulation sources such as envelope generators or realtime sources such as velocity or key pressure can also yield very interesting results. Try them all out!

  • In the first Tutorial, we saw how two different voices within a program can access different parts of the same wave-list. Bear in mind, however, that up to four voices within a program can access the same list, with each voice independently accessing any area of the list. For example, one voice might access wave steps 1–8, while a second one accesses steps 3–6, a third one accesses steps 9–16, and a fourth one accesses steps 2–10. The DELAY parameter (in the main Wave page) allows you to stagger the onset of each voice; this feature enables the construction of extremely complex sounds from a single wave-list. To demonstrate, call up the program created in the second Tutorial. Make sure all four voices are unmuted and select the second voice (SHAKU) so that it is underlined. Press the Wave button and change the wave for this voice to WAVE-LIST. Use the same procedure to change voices three and four so that they too use the WAVE-LIST wave. In the Wave page, set each of the three voices to access a different area of the wave-list. For example, you might set the LOOPSTART value of voice two to 6, with an END value of 12 (so that this voice loops through steps 6 through 12); voices three and four can be set in a similar, random way. Then set the DELAY time for voice three to 500 msec; for voice four to 1000 msec; and for voice two to KYUP. In the Voice Select page, solo voice two and play and hold a note on the keyboard; you won’t hear much of anything at this point, since the release time for this voice is too fast. Accordingly, press the Envelope 3 button and change the release time to a new value of 80. Now unsolo voice two in order to hear all four voices play together. The sonic result is a beautiful blend of constantly changing timbres, with an additional “bonus” of a new timbral shift (added by voice two) when the key is released.

  • Taking this concept further, you can stack up to three Hyper-Wave programs (each playing up to four Hyper-Wave voices) in a Preset. All of the various Preset editing functions are then available, allowing you to quickly and easily create velocity ranges and keyboard zones, and so on, for these programs, as well as giving you live performance control over parameters such as volume, panning, attack, release, brightness, timbre, velocity sensitivity, and response to real-time controllers.

  • Last but not least, here’s an undocumented tip that doesn’t appear in the TS‑10/TS‑12 Musician’s Manual: you can copy a wave-list from one program to another simply by pressing the Copy button from within the Wave-List Editor. Select the MAKE COPY option, then call up the program into which you wish to copy the wave-list parameters. If the destination program doesn’t already have a wave-list, add one by changing the OPTION parameter in the Program Control page. Then go to the Wave-List Editor and press the Copy button once again, this time choosing the RECALL option. The entire wave-list (including all TIME and PITCH parameters) from the original voice are now copied into the new voice, ready for further editing as necessary.
