TS‑10 / TS‑12 · Hyper-Wave Programming

II. Tutorial: Creating an Original Hyper-Wave Voice

Here’s a tutorial that takes you through all the basic steps involved in creating an original Hyper-Wave voice “from scratch.” In the process, you’ll learn much more about how each of the Hyper-Wave programming parameters affects the overall sound.

  1. Begin by pressing the Sounds button and select any program. Again, remember that the TS‑10/TS‑12 utilizes a special area of memory called an edit buffer in which your edits are temporarily stored (this is described on page 129 of the TS‑10/TS‑12 Musician’s Manual). This ensures that no data is lost or overwritten until you specifically Write it to memory, so you can safely select any program at all for this editing procedure.

  2. Press the Select Voice button, followed by the Copy button. The display will change to the Copy page, with the following options:

    Note that the ALL VOICE PARAMETERS context (shown on the top line) and DEFAULT option (in the lower left-hand corner) appear because you entered the Copy page directly from the Select Voice page. Press the soft button under the DEFAULT option in order to create a default voice. This gives you a good starting point from which to do any TS‑10/TS‑12 programming “from scratch.”

  3. Also, since Hyper-Wave voices (like all other TS‑10/TS‑12 voices) are under the control of all three envelope generators, use the Copy function to assign a default “Full On” envelope to each of the three. To accomplish this, start by pressing the Envelope 1 button, followed by the Copy button. The following options will be presented:

    This time, the ENVELOPE-1 PARAMETERS context is shown, since you entered the Copy page directly from the Envelope 1 page. Press the soft button under the DEFAULT option and select the FULL ON envelope type, then press the *YES* soft button to execute the command:

    Repeat the process by pressing the Envelope 2 button, followed by the Copy button (so that the ENVELOPE-2 PARAMETERS context is displayed) in order to enter the same default “Full On” envelope. Finally, repeat the process one last time, this time pressing the Envelope 3 button, followed by the Copy button (so that the ENVELOPE-3 PARAMETERS context is displayed).

  4. As a last step in the preparation process, we’ll temporarily disable the TS‑10/TS‑12 Effects processor so that you can clearly hear every sonic nuance (without the addition of Effects) while you are “tweaking” the voice. To do so, press the Program Effects button and select EFFECT=00 DRY/BYPASSED:

  5. Next, press the Program Control button to enter the Program Control page. The display will look something like this:

  6. If it is not already underlined, press the soft button above the OPTION parameter in order to underline it. Then press the Up Arrow button. The display will read:

  7. Note that the top line of the display reads “REPLACE VOICES 5+6 WITH…” Whenever you create a Hyper-Wave voice (that is, a sound that uses a wave-list), the TS‑10/TS‑12 automatically deletes voices 5 and 6, using the memory normally occupied by those parameters to store the wave-list data. Also, note that the total polyphony of the instrument is halved when playing a program that utilizes one or more wave-list voices. This is because each key played uses two notes of polyphony in order to allow smooth crossfades between each wave step. Press the soft button under WAVE-LIST in order to replace voices 5 and 6 with wave-list data. The display will change to the Select Voice page, which now includes the EDIT WAVE-LIST option:

  8. Here, the TS‑10/TS‑12 gives you the opportunity to select which of the four voices in the program is to receive a wave-list. The first voice (with the SAW-WAVE2 wave name) is the one that has received the default settings, so that is the one we’ll choose. It will also be easier to hear your edits if the other voices in the program are muted. Accordingly, solo the first voice by double-clicking on it. The display will look like this:

  9. Press the Wave button and select the Wave Class Category (top line center):

  10. Move the Data Entry Slider all the way up in order to choose the WAVE-LIST category. The selected voice within your program is now playing a factory default wave-list over and over in a loop, as you will hear if you play and hold down a note on the keyboard. This default wave-list contains sixteen wave steps, with each playing for the same duration and crossfading gently into the next. The internal ROM waves being played by each of these sixteen wave steps are:

    • Step 1: TENOR-SAX (pitch normal)
    • Step 2: TUBA (pitch normal)
    • Step 3: CHOIR (pitch normal)
    • Step 4: OPN-HAT-1 (pitch normal)
    • Step 5: CLARINET (pitch normal)
    • Step 6: TUBA (pitch normal)
    • Step 7: ELEC-GTR2 (pitch normal)
    • Step 8: WURLIE-LO (pitch normal)
    • Step 9: BELL-XWV1 (pitch normal)
    • Step 10: TUBULAR (pitch normal)
    • Step 11: ORG-WAVE6 (pitch normal)
    • Step 12: SOPRN-SAX (transposed +02 semitones)
    • Step 13: SOPRN-SAX2 (transposed +05 semitones)
    • Step 14: ALTO-SAX (transposed +07 semitones)
    • Step 15: TENOR-SAX (transposed +10 semitones)
    • Step 16: EL-BASS-1 (pitch normal)

    The pitch transpositions in steps 12–15 account for the arpeggio you hear towards the end of each repetition. Note also that the duration of each wave step remains constant regardless of the note you play on the keyboard; you can even play chords, with each note in the chord cycling through the wave steps at the same time. However, if you play an arpeggiated chord, each note will cycle through the wave steps at different points, creating an interesting effect.

  11. We’ll get down to the nitty-gritty of editing the default wave-list shortly, but first let’s examine the various parameters provided by the Wave page display when the current program contains a wave-list. The DELAY parameter (range: 0000 to 5000 msec or KYUP) determines how long the voice will wait after a key is struck before playing. If you want your wave-list to play immediately when you strike a key, leave this parameter set to 0000 (no delay). If you want the wave-list to play at some point after the key is struck (for example, if you want other voices within the program to play first, with the wave-list coming in or fading up later), you can use this parameter to delay its entry for up to five whole seconds (5000 msec). The KYUP parameter is particularly interesting; when selected, the wave-list will not play until a key is released. In order to hear this effect, you’ll need to have a fairly high release time set in Envelope 3. Experiment with various DELAY times, listening carefully as you do so; when you’re done, return it to its default value of 0000 and move on.

  12. The START-STEP, LOOPSTART, and END parameters all allow you to specify what part of the total wave-list you wish to hear when a key is pressed. START-STEP determines the starting step number when a key is initially struck; LOOPSTART determines the starting point of the repeating loop (remember, Hyper-Wave voices always play wave-lists in continuous loops), and END determines the last step played before looping back to play the LOOPSTART step. To illustrate, suppose you enter a START-STEP of 4, a LOOPSTART of 6, and an END of 10. When you then strike a key, you’ll hear wave steps 4–10 play, followed by wave steps 6–10, which then loop continuously (as long as Envelope 3 permits). If you want to hear all sixteen wave steps, simply leave the default values (START-STEP=01; LOOPSTART=01; and END=16). Again, experiment freely with changing these values, listening carefully as you do so. When you’re done, restore the default values.

Bear in mind that Hyper-Wave voices, like all other TS‑10/TS‑12 sounds, are always under the direct control of all three envelopes as well as being affected by all other parameters (such as filters, modulation sources, etc.).

  1. If you press the Wave button a second time, you’ll be taken to the Wave Modulation page, which shows the various modulation options available to a Hyper-Wave voice—we’ll talk about these options shortly. Bear in mind that a Hyper-Wave voice does not have to necessarily utilize all sixteen wave steps; as we’ve seen, the START-STEP, LOOPSTART, and END parameters all allow you to specify which steps you wish to hear. For the purposes of this Tutorial, we’re going to utilize wave steps 1–8 to create a drum pattern and steps 9–16 to create an accompanying bass pattern. Ultimately, we’ll have both parts play together. For now, though, set the current voice (voice 1) to play only the drum pattern contained in steps 1–8. Accordingly, press the Wave button once again in order to return to the main Wave page and change the END parameter to a value of 08, leaving the START-STEP and LOOPSTART parameters at their default values of 01:

  2. Now we’re ready to begin constructing a custom wave-list. To do so, we’ll need to enter the Wave-List Editor, accessed by returning to the Select Voice page (press the Select Voice button) and then pressing either of the soft buttons under the EDIT WAVE-LIST option (lower center or lower right-hand corner). Here’s what the main Wave-List Editor page looks like:

  4. The WAVE NAME and WAVE CLASS parameters (upper center and upper right-hand corner) allow you to specify which internal ROM wave you wish to assign to the selected step. Start by selecting the FAT-KICK wave from the DRUM-SOUND wave class for step 01:

  5. Use the same procedure to select the following internal ROM waves for each of the first eight wave steps:

    Then select the SYNBASS-1 wave (from the BASS-SOUND wave class) for steps 9–16.

  6. The START parameter (in the lower left-hand corner) allows you to set the internal starting time for the selected wave. It has a range of 00 to 99, with larger values corresponding to later start times. When set to 00 (the default), you’ll hear the selected wave from its beginning. When set to larger values, the wave starts at a later point. The main function of the START parameter is to allow you to delete the initial (attack) portion of a sound; this is mainly useful when you are trying to create smooth transitions between consecutive wave steps. Leave it at its default of 00 for wave steps 1–12, but change the START time for steps 13–16 to a new value of 20 (this will cause the last four notes of the bass pattern to sound without their attacks, making for a more realistic effect).

  7. If you play a key on the keyboard, you’ll hear a definite drum pattern, but all the steps (after the initial attack) are somewhat muffled. The reason for this has to do with the default crossfade settings which are still being applied. Press the soft button under the *TIME* option (lower center) in order to enter the Time sub-page:

    The STEP parameter (upper left-hand corner) allows you to select the wave step you wish to edit. Select Step 01. The duration (DUR) parameter (upper center) enables you to specify the duration of the selected wave step, in increments of 12 milliseconds. The range of this control is 00000 to 60000 (60 seconds). For now, leave the duration of wave step 1 at its default of 192. The volume (VOL) parameter allows you to independently adjust the level of each wave step, over a range of −50 to +14 dB, with +00 dB (the default value) indicating no attenuation or boost in level. For now, leave the volume of wave step 1 at its default of +00. The crossfade time parameter (XFADE-TIME) determines the amount of time that the currently selected wave step will use to fade out while the next wave step fades in. Like DUR, the range of this parameter is 00000 to 60000 ms (60 seconds). When a value of 00000 is selected, there is no crossfade time; the currently selected wave step will play throughout its duration at the specified volume. When a value of greater than 00000 is selected, the DEPTH parameter comes into play. This has a range of 0 to 6 dB. Greater values cause the crossfade curve to be steeper (thus yielding more apparent sonic changes), while smaller values result in a gentler curve, with more subtle sonic changes. Crossfades are useful when you’re using a wave-list to create a continuous complex timbre, but, when you’re using a wave-list to construct a distinct series of notes (like we are doing in this Tutorial for both the drum and bass patterns), you won’t want any crossfades at all. Accordingly, set the XFADE-TIME of all wave steps (steps 1–16) to a value of 00000. Now play a note on the keyboard again—this time, you’ll hear all drum sounds at their full volume.

  8. Because the duration of each of the eight wave steps is currently identical (192 milliseconds), you’re hearing a very regular—in fact, some might say, boring—drum pattern. To spice it up a little, change the duration of wave step 4 to 96 (making it half as long) and that of wave step 5 to 288 (making it one and a half times as long). The effect will be equivalent to that of hearing an eighth note followed by a dotted quarter note. You can add a little more “feel” to the pattern by extending the duration of step 6 ever so slightly, changing it from 196 to 204. This will have the effect of making the beat just a bit “laid back”—and will also serve to reduce the mechanical aspect of the pattern. We’re also going to want to have the bass pattern closely match the timing of the drum pattern, so enter the same duration values in steps 9–16 that you just did in steps 1–8, as shown in this table:

  9. One thing you may have noticed at this point is that the pitch of the drum pattern changes as you play different notes on the keyboard. While this may be desirable for some Hyper-Wave voices, you’ll probably prefer to have a drum pattern stay at the same pitch, regardless of the note played. This is easily accomplished by going to the Pitch sub-page, accessed by pressing the soft button beneath the *PITCH* option (lower right-hand corner) in the Wave-List Editor page:

    As with the Time sub-page, the upper left-hand corner contains a STEP parameter, allowing you to choose which of the sixteen wave steps you wish to edit. The PITCH-KBD-TRK parameter in the lower left-hand corner enables you to specify whether a particular wave step will respond to the pitch played by the keyboard (as determined by the currently selected System pitch-table) or whether it will ignore it. Since we want all eight steps in the drum pattern to ignore the keyboard, set this parameter to OFF for steps 1–8. Steps 9–16 (which will provide an accompanying bass pattern) should all be left at their default ON settings so that the pitch of the pattern can be freely transposed by playing different notes on the keyboard.

  10. The Direction (DIR) parameter (upper center) allows you to specify whether you want a wave step to play forward or backwards. This works just like the equivalent DIR parameter on the Wave page of non-Hyper-Wave voices; when set to REVERSE, the wave is literally turned around. Experiment with each of the eight wave steps in the drum pattern—you’ll hear some really wild effects! As a suggestion, you might try reversing the direction of the three closed hi-hat sounds (steps 2, 4, and 8). Leave the direction of steps 9–16 at their default FORWARD settings.

  11. The Transpose (XPOS) and DETUNE parameters (lower center and right) are used to alter the pitch of individual wave steps. XPOS values can range from −36 to +36 semitones, while the much subtler DETUNE parameter provides values that range from −99 to +99 cents (a cent is 1/100th of a semitone). For example, to make all the kick drum sounds slightly deeper, set the DETUNE parameter for wave steps 1, 5, and 6 to a new value of −50. Conversely, to make the hi-hat sounds a bit brighter, change the XPOS parameter for wave steps 2, 4, and 8 to a new value of +02. If you’re into really fine “tweaking,” you can literally set each wave step to a slightly different pitch, more closely emulating the subtleties of an acoustic drummer. You can even change XPOS and DETUNE values “on the fly,” entering them for specified steps while the loop is playing.

    Next, we’re ready to program the pitches for our accompanying bass pattern. Enter the following XPOS values for steps 9–16:

  12. To hear the bass pattern play back, press the Wave button and change both the START-STEP and LOOPSTART values to 09. Then change the END value to 16. Play various notes on the keyboard; because wave steps 9–16 (unlike wave steps 1–8) have their PITCH-KBD-TRK value set to ON, you’ll hear the pattern transpose as you play different notes.

    However, the tempo and rhythm of the pattern remain constant!

  13. As mentioned previously, Hyper-Wave voices can also be modulated in a variety of interesting ways. Now that we’ve built a custom wave-list, let’s see how this works. Press the Wave button a second time in order to view the Wave Modulation sub-page:

    Here, any of the TS‑10/TS‑12’s fifteen standard modulation sources (MODSRC) can be applied to any of five possible destinations (MOD-DESTINATION), with an adjustable MODAMT parameter that allows you to apply negative or positive amounts of modulation signal, over a range of −15 to +15 (a value of +00 means that no modulation signal is being routed). The best way to understand how this works is to actually try each of the five possible modulation destinations, so begin by selecting WHEEL as the MODSRC, and set a MODAMT of +15 for maximum effect. In the default voice (the voice we originally edited to create the wave-list), the modulation wheel is used to determine both LFO rate and depth, so we’ll want to disable these functions so that we won’t be confused by the addition of vibrato when the wheel is raised. Accordingly, press the LFO button and change the MODSRC for both LFO rate and depth to *OFF*, as shown below:

    Next, return to the Wave page by pressing the Wave button, and restore the START-STEP and LOOPSTART values to 01, and restore the END value to 8 (this will allow us to hear the drum pattern once again). Then go to the Wave Modulation sub-page by pressing the Wave button a second time. Now we’re ready to explore the effects of applying modulation to each of the five possible destinations.

The fifteen TS‑10/TS‑12 wave-list modulation sources are: Low Frequency Oscillator (LFO); Noise Generator (NOISE); Envelope 1 (ENV-1); Envelope 2 (ENV-2); Mod Mixer/Shaper (MIXER); Modulation Wheel and Key Pressure (WL + PR); Key Pressure and Velocity (PR + VL); Modulation Wheel (WHEEL); Pitch Bend Wheel (PITCH); Voltage Control Foot Pedal (PEDAL); Timbre Control (TIMBR); External MIDI Controller (XCTRL); Channel Key Pressure (PRESS); Keyboard Tracking (KEYBD); and Velocity (VELOC). In addition, a sixteenth option (*OFF*) signifies no modulation source. When this is selected, no modulation signal is routed, regardless of the MODAMT value and the selected MOD-DESTINATION.

  1. When START-STEP is selected as the modulation destination, the modulation source (in this case, the wheel) alters the starting step played by the wave-list. To hear how this works, start by playing and holding down a key with the wheel all the way down. In obedience to the START-STEP, LOOPSTART and END parameters we originally set on the Wave page, the drum pattern faithfully begins at step 1, plays through to step 8, and then plays steps 1–8 in a continuous loop. Now raise the wheel slightly and play a key. At a certain point, you’ll hear the drum pattern start at step 2 instead; as always, after the first play-through, it loops from steps 1–8. Raise the wheel a little more and play a note again; this time, the drum pattern starts at step 3. Each time you raise the wheel, the drum pattern starts at a later point, but it always loops from steps 1–8 after the first play-through. When the wheel is placed above the halfway point, you’ll start hearing a bass note (from one of the steps 9–16) before the drum pattern begins; this is because the modulation source (in this case, the wheel) is causing the wave-list to start playback at a point after its specified end point (in this case, step 8). When this occurs, the TS‑10/TS‑12 plays that new start-step for its programmed duration and then immediately jumps into the specified loop (in this case, steps 1–8).

    Now try lowering the MODAMT to a new value of +08. You’ll find that moving the wheel causes the same thing to occur, but that you have to move the wheel approximately twice as far to get the same effect. At a MODAMT of +08, for example, you’ll have to move the wheel all the way to the top—not just more than halfway—in order to hear a bass sound precede the drum pattern.

    Finally, try changing the MODAMT to the maximum negative value of −15. With the current settings, it will have no effect whatsoever, since both the START-STEP and LOOPSTART values are 01 (and you can’t start playback from any earlier point). Press the Wave button and temporarily change the START-STEP value to 04. Play a note on the keyboard with the wheel fully down. As you might expect, the drum pattern now begins at step 4 and then loops from steps 1–8. Raise the wheel all the way to the top and play a note again. This time, the wheel is having the maximum negative effect, causing the drum pattern to once again begin playback from step 1. With the wheel halfway (or with half the MODAMT, say to −08), the drum pattern begins playback from step 2 or 3 before going into a loop. Before moving on, change the START-STEP parameter back to its original value of 01.

  2. When LOOP-START is selected as the modulation destination, the modulation source (in this case, the wheel) alters the first step of the continuous loop played by the wave-list. As before, start by playing and holding down a key with the wheel all the way down. Again, the drum pattern faithfully begins at step 1, plays through to step 8, and then plays steps 1–8 in a continuous loop. Now raise the wheel slightly and play a key. At a certain point, you’ll hear the loop change to steps 2–8 (the pattern begins with a closed high-hat instead of a kick drum). Raise the wheel a little more and play a note again; this time, the loop changes to steps 3–8 (starting with a snare drum). Each time you raise the wheel, initial play-through is the same, but the loop starts at a later point, always going through to step 8 (the specified END value). When the wheel is placed above the halfway point, you’ll hear a loop of a single bass note (from one of the steps 9–16) after the first play-through; this is because the modulation source (in this case, the wheel) is causing the wave-list to start looping at a point after its specified end point (in this case, step 8). When this occurs, the TS‑10/TS‑12 continuously loops through that one step, stopping only when you release the key and play a new note.

    Just as before, applying lesser amounts of positive modulation causes the modulation source (in this case, the wheel) to have less effect, and the application of negative amounts of modulation results in the inverse effect. In this particular case, negative amounts of modulation will have no effect, since the specified LOOPSTART point is step 01 (and you can’t begin a loop any earlier than that). However, if you experiment by changing the LOOPSTART point, you’ll be able to hear the effect of negative modulation. When you’re done experimenting, restore the LOOPSTART value to 01 and set the MODAMT value back to +15.

  3. When END-STEP is selected as the modulation destination, the modulation source (in this case, the wheel) alters the end step. As before, start by playing a key with the wheel all the way down—everything plays through normally. In this particular case, however, if you raise the wheel slightly, you’ll hear the first note of the bass pattern at the end of each loop (since the wave-list is now looping through steps 1–9 instead of 1–8). The further forward you move the wheel (which is applying positive modulation), the longer the loop. As a result, you’ll hear more of the bass pattern in each repetition. When the wheel is placed past the half-way point, you’ll hear the entire bass pattern play through after each drum pattern—the wave-list is now looping through all sixteen steps.

    As before, applying lesser amounts of positive modulation causes a lesser effect. For example, if the MODAMT is changed to +08, you’ll need to move the wheel all the way up to hear the entire bass pattern play after each drum pattern loop. Negative modulation amounts will result in the inverse effect, with the end step being moved forward (instead of back) as greater modulation amounts are applied. In this case, the overall length of the loop is shortened instead of lengthened.

  4. Probably the most interesting effects can be generated by selecting TRAVELER as the modulation destination. Here, only one wave step at a time is played (for its specified duration, but in a continuous loop)—but the particular step that is played is determined solely by the modulation source. To demonstrate, set the MODAMT to +15 (maximum positive modulation), leaving the wheel as the modulation source. Choose TRAVELER as the modulation destination and, with the wheel completely down, play and hold down a note on the keyboard—you’ll hear a continuously repeating kick drum sound (the first step in the wave-list). Now, while continuing to hold the note, move the wheel up slightly—you’ll hear a closed hi-hat sound (the second step in the wave-list). Continue moving the wheel while holding down the note—one by one, you’ll hear each wave step, in order, played on its own in a continuous loop. By adjusting the wheel in real time, you can create a wild new piece of music out of just these sixteen wave steps!

    With a smaller positive modulation amount, the modulation source (in this case, the wheel) has less effect. For example, set the MODAMT to +08 and repeat the above experiment. This time, even with the wheel full up, you’ll hear just the ninth step (the first note in the bass pattern). Negative modulation amounts, as usual, have the opposite effect. In this particular case, a negative modulation signal will have no effect, since the START-STEP is currently at its lowest value (01). If, however, you change the START-STEP to a larger value, you’ll be able to hear this inverse effect (when you’re done experimenting, be sure to restore the START-STEP value back to 01).

  5. The final modulation destination option is called START+LOOP. This causes all three values—START-STEP, LOOPSTART, and END—to be modulated simultaneously. In effect, this creates a kind of “fixed window” which is superimposed over the wave-list loop. To demonstrate how this works, once again set the MODAMT to +15 (maximum positive modulation), with the wheel still serving as the modulation source. Choose START+LOOP as the modulation destination and, with the wheel completely down, play and hold down a note on the keyboard. You’ll hear the complete eight-step drum pattern play through and loop continuously, as usual. Now, while continuing to hold the note down, move the wheel slightly up. At a certain point, you’ll hear the loop change to include a single bass note (the first note of the bass pattern—that is, step 9) instead of the first note of the drum pattern (that is, step 1). What you have done is to shift the “window” forward so that the loop starts at step 2 (instead of step 1) and ends at step 9 (instead of step 8). While continuing to hold down the note, move the wheel up a bit more until you hear the first two notes of the bass pattern (steps 9 and 10) enter the loop in place of the first two notes of the drum pattern (steps 1 and 2). This time, the “window” has been shifted so that the loop starts at step 3 and ends at step 10. Keep moving the wheel up while continuing to hold down a note. As you get above the halfway point, the loop begins shortening, first containing only steps 9–16, then 10–16, then 11–16, and so on. At the topmost position, you’ll hear only a single note—step 16, the last note in the bass pattern—looping continuously. As with all other modulation routings, lesser positive modulation amounts yield a lesser effect, and negative modulation amounts yield an inverse effect, shifting the “window” backward.

  6. At last—the moment of truth: Let’s see how our drum pattern works along with the bass pattern by having both play simultaneously. To do so, we’ll need to give one voice within our program the job of playing the drum pattern while another one has the job of playing the bass pattern. Accordingly, press the Wave button and make sure that the current voice has the following settings: START-STEP=01; LOOPSTART=01; and END=08. Then press the Write Program button and save your work to a user program location. Next, press the Voice Select button and make sure that the first voice is selected and soloed (underlined with asterisks on either side)—it will be the only one named WAVE-LIST. Press the Copy button to enter the Copy page with the ALL VOICE PARAMETERS context:

    Press the soft button under the MAKE COPY option (lower right-hand corner); after a second or two, the display will read COPY COMPLETED. Now press the Voice Select button once again and select and unmute the second voice by pressing the soft button over it twice. The screen should look something like this:

    Press the Copy button once again—as before, you’ll see the Copy page with the ALL VOICE PARAMETERS context. This time, however, press the soft button under the RECALL option (lower center). After you see the COPY COMPLETED message, press the Select Voice button. The TS‑10/TS‑12 has copied the data from the first voice (the one with the wave-list) to the second voice:

    At the moment, both voices are completely identical, and if you play a key on the keyboard, you’ll simply hear the drum pattern (which will sound slightly flanged since it is being doubled). To change the situation, press the Wave button and change these parameters as follows: START-STEP=09; LOOPSTART=09; and END=16. This second voice is now playing the bass pattern, while the original first voice is simultaneously playing the drum pattern—and, since we selected the same relative durations for each, the two are in complete synchronization. Play the keyboard and jam away! To add a little “icing” to the cake, you might want to press the Program Effects button in order to go back to the Program Effects pages (remember, the sound we are listening to is completely dry at the moment) and add the effects of your choice. Don’t forget to save your work one last time.

    Bear in mind that the other two voices in your program are still ready and waiting to make a contribution—all you need to do is to unmute them to bring them to life. These other voices can play “normal” waves or can access other parts of the program’s wave-list.
